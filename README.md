# Lotfolio MVP

같은 종목의 매수분을 하나의 평단가로 합치지 않고, 매수 로트와 가상 포트폴리오별로 관리하는 개인용 Streamlit 앱입니다.

## 주요 기능

- KRX 종목 검색 및 직접 종목 등록
- 매수할 때마다 독립된 로트 생성
- 가상 포트폴리오별 포지션 분류
- 매도 시 차감할 매수 로트와 수량 직접 선택
- 로트별 현재가, 평가손익, 수익률 표시
- 포트폴리오별 손익 차트
- 전체 거래 및 실현손익 CSV 내보내기
- SQLite 로컬 저장

## Windows 실행 방법

PowerShell에서 압축을 푼 폴더로 이동한 뒤 실행합니다.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

명령 실행 후 브라우저에서 `http://localhost:8501`을 엽니다. 보통 자동으로 열립니다.

## 사용 순서

1. **가상 포트폴리오**에서 `장기투자`, `단기매매` 같은 전략을 만듭니다.
2. **종목 관리**에서 종목을 검색하거나 직접 등록합니다.
3. **거래 입력**에서 매수를 기록합니다. 매수 건마다 별도 로트가 생성됩니다.
4. 매도 시 포트폴리오와 종목을 고르고, 줄일 로트별 수량을 지정합니다.
5. **대시보드**에서 로트별 수익률을 확인합니다.
6. **거래내역·CSV**에서 기록을 내려받습니다.

## 시세 조회

FinanceDataReader로 국내 종목 목록과 최근 종가를 불러옵니다. 네트워크나 제공처 문제로 자동 조회가 실패하면 **종목 관리**에서 저장한 수동 현재가를 사용합니다. 해외 종목도 코드와 이름을 직접 등록해 기록할 수 있지만 자동 시세 호환은 코드에 따라 달라질 수 있습니다.

## 데이터와 주의사항

- 데이터는 앱 폴더의 `lotfolio.db`에 저장됩니다.
- 백업하려면 앱을 종료한 뒤 `lotfolio.db`를 복사하세요.
- 앱에서 지정한 로트는 투자 성과 분석을 위한 가상 분류입니다. 실제 증권사의 세금, 취득가액 및 매도 손익 계산 기준을 변경하지 않습니다.
- 로그인과 암호화가 없는 개인 PC용 MVP이므로 인터넷에 그대로 공개하지 마세요.
